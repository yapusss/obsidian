# Basis Pengetahuan Hermes

Folder ini adalah knowledge base jangka panjang milik Hermes (dan pemilik vault).
Isinya fakta, riset, jurnal, dan pengetahuan yang disimpan permanen — berbeda
dari memory tool (fakta singkat yang otomatis masuk konteks tiap sesi).

## Aturan pemakaian
1. Setiap catatan memakai frontmatter:
   `type`, `created` (YYYY-MM-DD), `source: hermes`.
2. Gunakan wikilink `[[Nama Catatan]]` untuk menghubungkan topik.
3. File bertema umum boleh di `_knowledge/`; catatan harian/keseharian masuk `Inbox/`.
4. Karena folder ini ikut tersinkron ke GitHub (auto-push 01:00 UTC server),
   isinya pasti ter-backup.

## Cara memakai
- Hermes: untuk menyimpan apa yang ingin diingat permanen (riset, keputusan,
  topik berulang), tulis di sini mengikuti format di `_TEMPLATE Knowledge.md`.
- Pemilik vault: baca/edit sama seperti catatan lain; backlink berfungsi lintas folder.
