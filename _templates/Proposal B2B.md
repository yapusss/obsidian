# Template — Proposal B2B (1 halaman)

> Template reusable untuk proposal ke badan usaha/PT. Duplikat file ini per-clien, isi bagian dalam `[...]`. Kirim SETELAH ada pembicaraan/kenalan, bukan sebagai langkah pertama.

---
> status: draft
> dibuat: 2026-09-15
---

## Header
```
Proposal: [Nama Sistem] untuk [Nama Perusahaan]
Dari: [Nama / nama bisnis]
Tanggal: [tanggal]   |   Kontak: [email + telepon]
Status: berlaku [30] hari
```

## 1. Masalah (mereka harus mengangguk baca ini)
> [Perusahaan] saat ini menangani [pesanan/permintaan/laporan] secara manual via [WhatsApp/spreadsheet]
> oleh [X] staf. Ini menghabiskan sekitar [estimasi jam hilang/bulan] dan menyebabkan
> [pesanan hilang / kesalahan / laporan telat].

Soal fakta dan spesifik ke *mereka*. Blok ini tempat mereka memutuskan kamu paham masalahnya.

## 2. Solusi & ruang lingkup
> [Web app / dashboard / sistem terintegrasi WhatsApp] yang:
> - melakukan A (mis. auto-capture pesanan …)
> - melakukan B (…)
> - melakukan C (…)
>
> Dibangun dengan [teknologi], dikirim dalam [X] tahap selama [Y] minggu.
> Dalam lingkup: [fitur]. Di luar lingkup: [sebut eksplisit biar tidak ada kejutan].

## 3. Timeline (milestone = kepercayaan)
| Fase | Yang kamu dapat | Kapan |
|---|---|---|
| 1 | Kontrak + setup, [deliverable pertama] | Minggu 1 |
| 2 | [fitur inti] berfungsi / demo | Minggu 2–3 |
| 3 | [fitur sisanya] | Minggu 3–4 |
| 4 | Testing, pelatihan, serah terima | Minggu 5 |

## 4. Harga — tetap, dengan justifikasi
```
Total: Rp [X]
- 30% DP untuk mulai
- 40% saat demo Fase 2
- 30% saat serah terima
Berlaku 30 hari.
```
Sebut harga dengan percaya diri. Kalau mau diskon besar, tukar dengan lingkup lebih kecil — bukan rate murah. Menurunkan harga mengisyaratkan kamu tidak percaya pada hasilmu.

## Penutup
> Saya sarankan mulai dengan [pilot berbayar 1 minggu / kickoff bertanda tangan] untuk mengunci lingkup.
> Langkah berikutnya: walkthrough 30 menit atas proposal ini — [link kalender].

---
## Aturan pakai
1. **Email intro dulu, proposal setelah.** Proposal dikirim setelah ada panggilan/kenalan, atau diminta.
2. **Target orang**, bukan `info@perusahaan.com`.
3. **Jangan sebut harga di email/chat** — tahan diskusi harga untuk proposal, setelah nilai disampaikan.
4. **Tawarkan pilot berbayar** sebagai pembuka terkuat untuk klien baru.
