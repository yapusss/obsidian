# Template — Email/Chat Intro Klien (kontak pertama)

> Template pesan pertama sebelum proposal. Reaksi terhadap INI menentukan apakah proposal pernah dibuka.
> Duplikat per-clien, isi `[...]`.

---
> status: draft
> dibuat: 2026-09-15
---

## Subjek
```
[Super incar] — sistem [ops/ticketing/pemesanan] yang bisa dikerjakan bulan ini
```

## Isi
```
Halo [Nama],

Saya menemukan [perusahaan] melalui [kenalan BEM / koneksi keluarga / postingan LinkedIn-mu]
dan melihat kamu menangani [bidang masalah — mis. pesanan WhatsApp manual].

Saya membangun [jenis sistem] untuk bisnis di skala itu. Untuk [tipe + ukuran perusahaan],
biasanya berarti [satu hasil konkret — mis. pesanan auto-tertangkap dari WhatsApp ke
dashboard, memangkas waktu admin setengahnya].

Maukah 15 menit minggu depan untuk cek apakah cocok?
Saya bawa demo singkat, tanpa komitmen.

[Nama]
[link ke 1–2 portofolio relevan]
```

## Aturan
1. **Satu masalah, satu hasil.** Maksimal dua kalimat untuk pitch.
2. **Sebut koneksi/referral di baris satu** jika ada — lever konversi terkuat.
3. **Tawarkan panggilan ringan** (15 menit + demo), bukan "mau saya kirim proposal?"
4. **Kirim ke orang**, bukan `info@`. Cari via LinkedIn, halaman tim di website, atau minta intro dari kenalan.
